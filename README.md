# ALTO Expeditions

Travel & adventure · Independent concept demo

An alpine journey that climbs through a mountain landscape before opening into an interactive route atlas.

**[Visit the live site ↗](https://northlight7.github.io/cinematic-alto/)** · [Project notes & screenshots](https://github.com/northlight7/web-design-portfolio/tree/main/projects/alto) · [Full portfolio](https://northlight7.github.io/web-design-portfolio/)

![Animated scroll preview of ALTO Expeditions](preview.gif)

## What to try

Scroll through the ascent, then choose a route to reveal its contour path and field notes.

## Design focus

A continuous camera ascent brings depth to the terrain. The landscape resolves into a route atlas instead of moving from side to side.

Three routes reveal matching contour paths and field notes. Hover and keyboard focus stay local to the controls.

## Run locally

This is a buildless static site. Serve this repository with a static HTTP server, for example:

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080 in your browser. Fonts, dependencies and visual assets are hosted locally with the site.

Created through AI-assisted design and development, iterative art direction and browser testing. This is fictional concept work, with no client affiliation or commercial results claimed. The animation condenses an actual browser scroll walkthrough into a short silent loop.
